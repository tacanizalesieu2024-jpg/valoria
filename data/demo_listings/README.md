# Demo listings

One folder per listing. The app shows them in **"Load a demo listing"** in the sidebar.

```
chamberi_example/
    listing.txt    the listing text (required)
    info.json      optional: neighbourhood, address, asking_price
    photo1.jpg     optional: 2-4 photos (jpg or png), e.g. kitchen, bathroom, living room
```

Neighbourhood must match one in the app's list (Sol (centre), Chamberí, Salamanca, Retiro,
Chamartín, Malasaña, Lavapiés, Argüelles, Tetuán, Arganzuela, Carabanchel, Puente de Vallecas),
or fill in an address instead.

For the live demo, prepare at least two: one fairly priced flat and one overpriced flat.
Use real public listings, and save photos only for this class project.
